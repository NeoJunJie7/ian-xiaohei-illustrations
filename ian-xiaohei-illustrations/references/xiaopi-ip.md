# xiaopi / 小pi IP

## 角色定义

xiaopi（小pi）是本仓库用于正文配图的主要视觉 IP。与早期的小黑设定不同，xiaopi 更偏向白色、圆润、戴头盔护目镜的角色形象（见仓库示例图）。

默认每张图都要出现 xiaopi。xiaopi 不是仅仅的表情包或吉祥物，而是参与并承担图内核心动作的角色。

## 外形

- 圆润的身体，简单轮廓，厚黑色线条描边，白色或极浅色填充。
- 头戴短檐头盔（短帽檐）并配有圆形护目镜（goggles）——这是关键识别元素。
- 小嘴/小喙，点状黑眼或简洁眼形，表情清晰但不过分可爱。
- 四肢简洁，常见姿势：站立、睡觉、思考、阅读、指点或拉扯物件。

## 性格

- 好奇、略带顽皮，但在图中表现为认真执行某件荒诞任务。
- 沉着冷静，带一点干涩幽默感。

## 常见职责

让 xiaopi 承担核心动作：

- 搬运素材、拉线汇聚信息源。
- 卡在断点里或拉扯某个“判断”杆。
- 变成筛选漏斗或站在承接路径上。
- 举警告牌、搭桥、分拣、记录、操作机器内部。

## 禁止

- 不要把 xiaopi 画成过度可爱的吉祥物或儿童插画风。
- 不要给 xiaopi 复杂服装、过度表情或闪亮眼睛。
- 不要把 xiaopi 当作纯装饰——它必须是动作主体。

## 判断标准

如果去掉 xiaopi，图的核心隐喻还能完全成立，说明 xiaopi 太装饰了；要重写提示词，让 xiaopi 成为动作主体。
